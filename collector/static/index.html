Ripristino completo: tutti i dati attuali vengono sostituiti da quelli del file. Prima viene creato in automatico un backup di sicurezza dello stato attuale.

Impostazioni

IP o hostname da cui leggere i dati, con porta facoltativa (predefinita 8123). Esempi: 192.168.1.50, homeassistant.local:8123, https://ha.example.com. Lascia vuoto per usare il valore del file .env:
